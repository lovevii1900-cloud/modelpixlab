Frequently Asked Questions

How does Verbatim detect invisible characters in ChatGPT or Claude output?

Verbatim iterates through every UTF-16 code unit in your input buffer and cross-references each character against the Unicode General Category Cf (Format), Cc (Control), and non-standard space tables, rendering inline hex badges in the X-Ray view.

Is any pasted text or source code sent over the network?

No. The entire inspection and normalization pipeline runs synchronously inside your local browser tab with zero external API requests, telemetry, or storage.

Will stripping zero-width characters affect normal multilingual text?

Standard English, Chinese, Japanese, Spanish, and European scripts do not require zero-width spaces. If you work with Indic or Arabic scripts that intentionally rely on U+200C/D joiners, you can toggle off the Zero-Width rule individually in the pipeline bar.
