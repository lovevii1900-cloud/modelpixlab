TL;DR verdict

Three honest paths: developers pay the raw API — roughly $0.013–$0.053 per 1K image depending on quality. ChatGPT subscribers already have it with no per-image billing. Is GPT Image 2.5 free to use?

How much does one GPT Image 2.5 image cost via the API?
OpenAI charges $30 per million output image tokens. Independent measurements put a 1024×1024 image at roughly $0.013 at medium quality and $0.053 at high quality. Token accounting can change, so treat these as a snapshot.
Is there a price difference between Flare and Sunburst?
No. OpenAI publishes identical token rates for both. Flare is tuned for fast everyday generation; Sunburst for precise editing — pick by task, not by price.
